# Content drop zone

Place media and text here — one folder per window.

**Visual hi-fi pass (Opus):** follow `defs/14_visual_assets.md` for every hub view, window chrome kit, icon, sticker, and minigame sprite path. Feel language: `defs/09_game_feel.md`. Shell lock: `DESIGN.md` / `PRODUCT.md`.

| Folder | What to put |
| --- | --- |
| `brand/` | Wordmark raster (`title-dopamine.webp`) — visual PR #8 |
| `ui/` | Shared OS chrome, stickers, overlays, per-window chrome kits (`14`) — #8 |
| `icons/` | Window logos (SVG) — #8 Phase D |
| `mockups/` | Screen & chrome references → hi-fi (`09` / `14`) — #8 |
| `minigames/` | First-party minigame art (`14` Phase E) + SFX paths (`15`) |
| `sfx/` | Hub/alert short audio + `manifest.json` (`15`) — produce `.ogg` after #8 |
| `credits/` | Credits Modal **data** — `store.json` + schema (`13`) |
| `loop/clips/` | Short videos + `manifest.json` (empty scaffold ready) |
| `loop/placeholders/` | Optional stills for mockups |
| `pulse/` | Authored posts / users / trends / seeds |
| `wave/high/` | High-paced / techno tracks |
| `wave/boring/` | Slow / throw-off tracks |
| `echo/audio/` | Long-form audio |
| `echo/video/` | Long-form video |
| `alerts/templates.json` | Optional hand notification lines |

Full rules + API notes: `defs/08_content.md`. Credits / attribution: `defs/13_credits_and_legal.md`. SFX: `defs/15_sfx_audio.md`.
