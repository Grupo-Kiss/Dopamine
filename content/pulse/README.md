# Pulse — text library + generators

All text. No audio/video required.

| File | Role |
| --- | --- |
| `posts.json` | ~100+ template posts (variables allowed). Ads/spam set `rewardable: false` |
| `trends.json` | Trend topics + provisional lifetimes |
| `users.json` | Fictional handles (no real people / real brands) |
| `generators/seeds.json` | Fragments for `{noun}`, `{place}`, `{topic}`, `{take}`, `{emoji}` (and `{user}` from `users.json`) |

`*.example.json` files remain as minimal schema stubs.

Categories (from `defs/03` / `08`): `harmless_trends`, `absurd_debates`, `ragebait`, `memes`, `controversial_opinions`, `fake_news`, `internet_drama`, `advertising`, `spam`.

See `defs/08_content.md`.
