# Design Pins

Short reminders agreed during design that belong in a later doc. Remove each pin when the owning document absorbs it.

## For `06_balance.md`

- Balance is **trial-and-error** during development; initial numbers are starting points, not final truth.
- Early Match must **ease / lure** the player in. Theoretical late-Match complexity can become too harsh if early pressure ramps too fast — prefer a gentle onboarding curve, then escalate.
- Burnout base APM and per-cycle threshold increases are balance tables (illustrative 80 → 100 → 125 already in core).

## For `09_game_feel.md`

- **Burnout Telegraph:** when APM approaches the current Burnout threshold, show a clear arcade-readable warning so the player can ease off (save Burnout) or push to enter it.
- Arcade multipliers for successive actions; Focus Chain uses old-arcade message overlays.
- Dual art: caricaturesque simple windows vs over-the-top minigame spectacle.

- **Negative Gain:** Dopamine is never removed directly — re-check if any future mechanic tempts a penalty exception (`02_gameplay_core.md`).
